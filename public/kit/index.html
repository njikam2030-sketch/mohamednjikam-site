Solution recommandée : laisser le site sur Vercel et brancher le domaine (voir ci-dessous). Ce fichier sert de copie de secours.
Télécharger le site (zip)

Brancher moharamadan.com (recommandé, 10 minutes)

  1. Vercel : projet mohamednjikam-site > Settings > Domains > ajouter moharamadan.com puis www.moharamadan.com.
  2. Hostinger : hPanel > Domaines > moharamadan.com > DNS. Supprimer les anciens enregistrements A sur @ et CNAME sur www.
  3. Ajouter A  @  76.76.21.21
  4. Ajouter CNAME  www  cname.vercel-dns.com
  5. Attendre « Valid Configuration » dans Vercel. Le site s'ouvre alors sur moharamadan.com, avec le cadenas HTTPS.
